# CI-FIB
# Prácticas de Interfaz de Computadores (CI) - FIB

Repositorio de soluciones para las prácticas de laboratorio de **Interfaz de Computadores (CI)**. 
## Contenido

Cada práctica contiene lo siguiente:

- **Código fuente**: El código en lenguaje C necesario para realizar la práctica.
- **Esquema del circuito**: El diagrama eléctrico correspondiente en formato Proteus.

El proyecto está disponible en formato `.pdsprj`, lo cual te permitirá cargarlo directamente en **Proteus**.

## Recomendaciones

- **Proteus v8.4 SP0**: Es recomendable usar esta versión para evitar problemas de compatibilidad entre diferentes versiones del software.
- **Compilador MPLAB-XC8**: Asegúrate de tener instalado el compilador **MPLAB-XC8** para compilar los programas en C de manera adecuada.

## Instrucciones para comenzar

1. Clona este repositorio o descarga los archivos directamente.
2. Abre el proyecto en **Proteus** usando el archivo `.pdsprj`.
3. Asegúrate de que **MPLAB-XC8** esté correctamente instalado y configurado en tu entorno de desarrollo.
4. Compila y carga el código para probar los circuitos.
